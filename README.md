# java-shareit

Сервис аренды вещей: пользователи публикуют вещи, ищут нужное и бронируют чужие вещи на заданные даты.

Проект разделён на два приложения:

- **gateway** (порт `8080`) - принимает запросы клиентов, валидирует входные данные и проксирует вызовы на сервер;
- **server** (порт `9090`) - содержит бизнес-логику и работает с базой данных PostgreSQL.

## Функциональность

- **Пользователи** - создание, обновление, получение по `id`.
- **Вещи** - создание, обновление, получение владельцем с последним и ближайшим бронированием, поиск по названию и описанию, комментарии пользователей, арендовавших вещь.
- **Бронирование** - создание, подтверждение или отклонение владельцем, получение по `id` и списком по состоянию (`ALL`, `CURRENT`, `PAST`, `FUTURE`, `WAITING`, `REJECTED`).
- **Запросы вещей** - создание запроса на вещь, получение своих запросов с ответами других пользователей, постраничный список запросов других пользователей, получение запроса по `id`. При создании вещи можно указать `requestId`, связывающий её с запросом.
